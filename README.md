# Spotify Playlist Generator – Musical Time Machine

Automate your music experience by generating Spotify playlists from any year or decade using **Python and Spotify API**.

## Features
- **Automated Playlist Creation:** Generate playlists from a specific year or musical era.
- **Spotify API Integration:** Seamless connection with your Spotify account.
- **Python Automation:** Fully automated process, perfect for learning and showcasing Python skills.
- **Customizable:** Adjust playlist length, genres, or era.
- **Data Handling:** Demonstrates advanced data extraction and manipulation skills.

## How It Works
1. User specifies a **year or decade**.
2. Python script fetches **top songs from that era**.
3. Script creates a **new Spotify playlist** in your account.
4. Enjoy your personalized musical journey instantly!
